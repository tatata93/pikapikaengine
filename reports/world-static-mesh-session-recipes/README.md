# Owned Native session prototype

Original independent owner wrapper, not a finished SDK or a general physics
model. No external source, image, runtime library or paid service is added.

Actual `run-20261105-prototype-001` / fresh `build/wfo1` passed4 commands,
13 lifecycle and5 numerical groups, actual imported default-model refusal,
three strict/WX/non-LTO compile logs and1938 unchanged protected paths.
It reads the accepted wfcqm2 four libraries/nine serializer objects and wfcq3
default parent without reconfiguration. Release ABI is MSVC19.51/x64/MD.

Reproduce only with fresh names, for example:

```powershell
python -B -X utf8 reports/world-static-mesh-session-recipes/check-prototype.py --build build/wfo2 --name run-20261105-prototype-002
```

The separate target token and request owner tag detect foreign slot/stale
generation before elapsed admission. Tags are explicit caller data, not
cross-registry authentication. Creation owns raw originals; numerical validity
belongs to the actual delegated scheduler. Reset stages privately and swaps;
destroy/reuse never reuses a generation. Maximum4 sessions; saturated slots retire.

No full owned-transcript/reference, new-owner source identity, actual Debug owner,
GNU/sanitizer/main CMake, busy/reentrant/allocator/post-child fault injection,
thread atomicity, SDK/WASM or game acceptance. The default check is an actual
Release default upstream library refusal, not a new Debug owner result.
