# 不確かさを保つ複数面光路と法線支持の共通出力

## 実装した範囲

独自C++の面交差・界面計算を、原点/方向/法線/屈折率の閉区間を保つ
[区間光学](../docs/OPTICAL_BOUNDS.md)へ拡張した。全boxに共通する根と分岐を
確定できなければ、中央値に置き換えず未確定を返す。
[複数面光路](../docs/OPTICAL_ROUTE.md)は指定された面と反射/透過の順序に従い、
全交点・方向・屈折率の区間を次の面へ引き継ぐ。幾何距離、光学距離、任意偏光に
対する保守的な電力比区間を累積する。途中失敗では最終光線を返さない。

[光路ラボ](../tools/optical-route-lab.html)には平行板、2回反射するゴースト光路、
Brewster角、2球面cap、合成Cauchy分散、原点/屈折率の幅、臨界境界を用意した。
450nmと650nmの例は同じ曲面形状で、位相屈折率の全区間を使う。
センサーXはそれぞれ約−0.05186998m、−0.04355106mで、包含区間が分離した。
曲面の開口半径は0.6m、厚さ0.2m以上を要求し、表示範囲内で面が交差しない。

これは指定光路の計算であり、自動的な最近傍面探索、全ゴースト列挙、
センサー画像積分、フレア/収差画像、回折・干渉、校正済みレンズは未実装。
電力は任意偏光への包含であり、各面で無偏光へリセットした積ではない。
Stokesの継続輸送と分岐光路同士の位相合成は後続とする。

物理では[read-only法線支持](../docs/SUPPORT.md)を共通出力へ追加した。
保持荷重、異なる質量、非直交接触、球対の接線速度による距離二階微分を扱い、
反力と法線加速度の相補条件を残差区間で検査する。
微小でも証明された接近は衝撃として拒否し、離反とrestを区別する。
接触候補は明示したgap帯内の近似境界であり、幾何学的な厳密接触の証明ではない。
摩擦支持・支持付き時間積分・一般形状への適用は未実装。
[支持ラボ](../tools/support-lab.html)は照会前後の全状態・荷重・時刻一致を表示する。

ABI v1への追加で44関数、主WASM361007B、glue43071B。
web build `4e0d00dbdb939b92`、26 modules。
全原本と出力のhashは[build manifest](../assets/pikapika-simulation.build.json)、
最終検証のhashは[記録](route-support-verification.json)に保持する。
新しい外部実行ライブラリ・材質データ・素材は取り込まず、独自SVG2枚と図解16記事へ更新した。

## 実行した検証

- Native MSVC19.51 strict、Emscripten6.0.13のstandalone実WASMで、区間光学20群・支持21群・光路23群。
- 区間幾何302family/1880区間、屈折率111family/1110区間を独立Fraction/256bit代数参照で検証。限定した族の解析的極値による包含であり、有限サンプリングだけから全域を主張しない。
- 2コーパスのNative/standalone/主WASMで3760+2220端点bit一致。
- 光路15完全入力fixtureはNative/standaloneで2595数値のbit一致、独立Fraction包含67件。主WASMで公開された1560数値の最大差0。
- 支持12完全入力fixtureはNative/standalone1566数値の最大差0、主WASM689数値の最大差0。全ケースでWorld状態と荷重を保持。
- 非直交の2面接触と異massの移動球対を独立解析値から追加した。支持の反復終了だけで成功とせず、負加速度と相補性の残差を検査。
- 光路の後段入力不正で失敗indexが0になる診断を修正し、3番目ならindex2を返して最終光線がないことを回帰検査。
- Native CTest16/16、全296検証群。Node175/175、skip0。web build/check成功。
- 既存30697値比較は最大絶対差6.821210263296962e−12で許容内。旧光学4116・面交差2400・分散1920端点bitとW1 Worldも再確認。
- コーパス切詰めとPython -Oの負例を拒否。独立読取レビューと有限メンバー診断は追加の検査であり、連続族の包含証明とは区別する。
