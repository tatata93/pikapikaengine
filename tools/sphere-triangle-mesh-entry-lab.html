DEFINED SEGMENT / ENTRY WINDOW

侵入の始まりを、
証拠のある区間へ絞る。

球中心の線分 p(s) = start + s(end − start)、0 ≤ s ≤ 1 を最大64面へ照会します。初期点のstrict正、安全な連続prefix、strict負の点witness、窓幅を揃えてentry windowを確認します。

sと窓幅は無次元です。窓は単一根・厳密な物理時刻・特定の衝突面を表しません。Worldの運動、一般CCD/TOI、跳ね返りや摩擦の応答は進めません。

実C++ WebAssemblyを準備中。操作にはHTTP/HTTPS配信とJavaScriptが必要です。

定義線分と、選択auditの包含box

path/point boxと任意のbinary64 anchorを区別します。anchorは厳密なp(s)とは限らず、点witnessにはE補正が必要です。

XY/XZ/YZへの説明投影です。表示上のbox拡張は証明の境界ではありません。有限な図を作れない入力でも数値packet/status/保存を変更しません。

全parameter領域 [0,1]

初期点、連続safePrefix、後方の証明島、全partition/current/frontier、bestWitness、windowは別の証拠です。極小区間のinkを最小1pxへ拡張しても、正確な両端や窓幅は下の数値のままです。

入力を編集し、一回照会する

位置・頂点・半径・距離はm。右手系、Y上。parameter sと許容幅は無次元。

start/end/radius・全三角形・parameterTolerance・品質と予算設定を編集します。既定のtolは1e-6、評価256/partition128/depth24。65面はhost拒否とし、切り詰めません。編集直後に旧結果と保存状態を消します。

全体判定・全保守候補ID・Work

entry_windowは開始窓の証拠、separatedは全closed [0,1]のstrict非接触です。initial_penetrationは開始時点の貫通で新規entry窓はありません。not_certifiedを安全やmissへ変えません。

照会前

candidateSurfaceIdsは全sourceの昇順保守集合です。lastMeshのnearest IDや選択面へ縮めません。workExact・既知refinement・保守upperを区別し、auditのdeltaと全体総計を分けます。未知blockは実使用0回ではありません。

初期点 s=0 の証拠

initial_pointの両certificateとaudit所属を確認します。initial:nullと証拠のある初期点を分けます。safePrefix:[0,0]は初期strict正のみでも成立し、正の長さを証明したとは限りません。

照会前

安全prefix・負witness・開始窓

windowのL/U・外向きwidth・tolと、bestWitnessのexactPathBounds/任意anchor/E/所属を別表示します。負witnessだけで窓が受理されたとは限りません。

照会前

全partition・current・未照会tail

最大128の全closed被覆とstate/auditIndex/blockedReason、全frontier/currentを保持します。bestWitness以後の未照会tailも残し、未知の狭さを証明へ置き換えません。

照会前

全closed証明島（最大128件）

島closed parameter両端depthstrict正のlower式包含auditIndex

後方の証明島は連続prefixへ飛び越して接続しません。lower/upper certificateは各式の包含であり、二つを真のgap範囲として扱いません。

全audit（初期点1件＋cell最大255件）

ordinalkind / cellparameter / outcomemesh status / reasondelta Work

row_failureの祖先は未知のまま表示します。後続の子cellの新しい証拠による窓成立を、祖先queryの成功へ書き換えません。全optional fieldsは選択audit欄と完全JSONで確認できます。

全sourceと、最後に返ったlastMeshの行

全64面の元順を保ちます。この表はlastMeshAuditIndexだけの結果です。選択auditが異なる場合に、そのauditのmesh診断へ移しません。

元ordinal面ID実query / status / reason候補prefix / 検査数 / sqrt反復lastMeshのpossible

選択audit全fieldsとlastMeshの所属

path/point bounds、任意anchor、R/E、両certificateとdelta Workを保持します。幾何の重ね表示はlastMesh所属が一致する場合だけです。異なる面のclosest/法線を平均しません。

照会前

lastMesh閲覧面の全候補prefix

面・辺・頂点の返却候補とKKT区間です。未照会行/null queryを成功結果へ変えず、未実行候補を補完しません。

照会前

入力・全結果・表示条件の保存

SDK未初期化。旧guard・瞬間query・JavaScript幾何への代替計算はありません。

snapshot:nullでもoriginalInputとechoを保持します。全source/設定、initial、証明島、partition/frontier/current、全audit、witness/window/全ID、lastMesh全行と候補、符号零を省略しません。入力上限64KiB、保存上限8MiB。scrollや図の縮尺は保存内容を変更しません。

照会前

結果を読む順序

  1. status/reason、snapshot、initialSeparationProven、workExactを確認します。形式拒否・loader拒否・host拒否・モデル結果を区別します。
  2. 初期点、連続prefix、全証明島、負witness、窓幅とtolを見ます。safePrefix:nullと[0,0]、未認証と受理窓を分けます。
  3. 全partitionの未知域とtail、auditの元評価順を確認します。閲覧auditとlastMeshAuditIndexの所属を比べます。
  4. 入力編集で旧表示が消えた後、新しい実queryを行います。投影/閲覧だけでは再queryしません。完全JSONに実行条件を残します。
