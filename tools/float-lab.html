COMMON C++ CORE / WEBASSEMBLY + WEBGPU

力を積分して、
箱の運動を確かめる。

共通のC++剛体・静水圧をWebAssemblyで実行し、状態をWebGPUで表示します。自重と浮力の釣合いから、上下動と復原を観察します。

動的剛体1体・接触なしの参照実験。青い格子は水面の位置を示す目印で、流体の描画・計算ではありません。波・流れ・抵抗・音声・CFD・箱形状の接触は未対応です。

水平な青い格子が水面 y=0m。箱の色付きの面が上面です。格子には接触しません。全没した箱も見えるよう、水面を不透明な面で覆っていません。

実際の状態の履歴

2Dグラフを表示できません。数値とJSONログを参照してください。

横軸はシミュレーション時間。上下動ではY[m]、復原ではZ軸の傾き[rad]を表示します。

実験を操作する

4×2×4m、質量16000kg、初期中心y=0.1m、初速0。水面の近くで上下に振動する参照です。

C++ WebAssemblyとWebGPUを準備中。HTTP/HTTPSと対応GPUが必要です。

計算核の情報は起動後に表示します。

計測JSONの概要

画面には概要を表示します。各tick・描画の全サンプルは全時刻JSONを保存から取得できます。

計算と描画の時間を分ける

運動は固定120Hz。描画は直前と現在の位置・回転を補間します。1回の描画で追いつく更新は最大24tickで、それを超えた時間は破棄量を表示・記録します。コマ送りは必ず1tickです。初期状態は停止し、非表示タブへ移ると停止します。

上下動の箱は一様な箱の主慣性を使います。全没の復原ケースでは質量32000kg、CoMの初期Y=−4m、排水原点をbody座標でCoMより0.5m上、Z傾き0.15radとし、慣性は[24000, 48000, 40000]kg m²を仮定します。姿勢や質量分布を実船の測定から決めたものではありません。

エネルギーの表示を読む

表示するエネルギーは、指定した静水圧の外部場に対する剛体の運動エネルギーと参照ポテンシャルの和です。上下動ではK+80000y²、全没の純Z回転ではK+160000(1−cosθ)を使います。初期値との差を隠す減衰や速度制限は加えません。

流体自体の反作用・運動エネルギー・水面変化を解いていないため、流体と剛体の全系の保存を実証した値ではありません。詳しい式・検証条件は共通剛体と静水圧の参照記録をご覧ください。

この動的サンプルはHTTP/HTTPS・WebAssembly・WebGPUが必要です。姿勢を自分で指定して力だけを調べたい場合は、静的な浮力ラボを使えます。

C++共通計算核による無接触1体の参照。シーン原本の回転形式は変更していません。WebGPUは実行時のquaternion姿勢を表示します。
