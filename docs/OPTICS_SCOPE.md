# 任意選択の高精度光学計算

2026-11-03のユーザー明示要求。レンズによるフレア・ゴースト・収差を反映し、利用者が必要に応じて高精度な光学計算を選べること。元仕様§5の撮像・高度光学を具体化する。現在のGGX直接光・露出・霧にはレンズ光学の計算経路はない。

## 必要なデータと計算

レンズの各面の曲率/非球面、間隔、材質の波長依存屈折率、絞り・開口、コーティング、センサーと焦点位置、光源の位置/形/放射量を持つ。実レンズの名称や見た目から構成・材質値を推測して実測再現と呼ばない。データには出典・単位・許諾・仮定を記録する。

1. 有限開口と撮像の基礎を、薄レンズ等の適用範囲を明示した計算と理論例で確認する。
2. 多面レンズを通る光線の屈折・反射・遮蔽を計算する。複数回反射によるゴースト、口径食、波長分散による色収差、球面収差・コマ・非点等の撮像への影響を評価する。
3. 幾何光学の範囲外となる回折等は、波動光学・複素瞳/点像分布関数などの適用条件を定義した経路で扱う。散乱、表面欠陥、偏光等も、採用モデルが必要な現象を説明できるかを調査する。
4. 限定シーンの高精度参照計算と、実行時の近似/事前計算/サンプル数を比較する。選択したモデル・誤差・サンプル数・性能をログへ保存する。

## 精度の受入

「厳密」を無条件の現実完全一致とせず、物理モデル・境界条件・入力データ・数値誤差が追跡でき、必要精度まで収束を検証できることとして扱う。Snell則、全反射、Fresnelの既知ケース、薄レンズの極限、開口による既知回折像、対称系、エネルギー収支、空間/波長/光路サンプルの収束など、独立した基準を対象モデルに応じて選ぶ。まだこれらを実装・検証した状態ではない。

ムービー用の表現設定とプレイ中の視認性設定を持ち、強度や無効化を選べるようにする。任意選択で高精度化しても、プレイ用プロファイルでの60fps目標・低遅延・照準の視認性の検証は省略しない。停止中/オフラインの参照計算は別モードとして明示する。未達の設定を勝手に低品質へ変えて合格にしない。

新たなレンズ処方や光学アルゴリズムの採用前に一次資料を確認する。本書は実装待ちの要件・受入境界であり、未閲覧資料や存在未確認の論文を引用していない。

## 最初の調査記録（2026-11-03）

[Pharr/Jakob/Humphreys, PBRT第3版§6.4 Realistic Cameras](https://pbr-book.org/3ed-2018/Camera_Models/Realistic_Cameras)本文を確認。面の曲率・間隔・屈折率・開口から経路を追う構成と、厚レンズ/薄レンズの近似範囲を設計の比較対象にした。同節の基本実装は反射を省略するため、それをそのまま使ってフレア/ゴースト対応とすることはできない。数表のレンズ処方・画像・コードは取り込まない。

[同第4版§9.3 Specular Reflection and Transmission](https://pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission)本文を確認。経路方向のSnell則と反射/透過配分のFresnel式、波長依存の屈折率、全反射、偏光を平均する条件を初期検証の基準へ使う。非吸収の単一界面と、吸収/膜/多重反射の系を分けて扱う必要がある。振幅・パワー・放射輝度の係数を混同しない。ここでも既成実装の移植やライブラリ導入はしていない。

次の光学実装の最小受入は、明示した媒質・波長・方向規約で単一界面の入出射を計算し、垂直入射、等屈折率、Brewster条件、全反射、逆向きの経路を独立な式と比較すること。その後に複数面・反射光路・分散・開口サンプルの収束へ進む。一般の非球面レンズや波動伝搬をこの初段で完了扱いにしない。
