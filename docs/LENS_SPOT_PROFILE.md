# 合成レンズの有限幾何点像profile

`engine/optical-camera.mjs` は reusable profile/保存読込/瞳節点生成を提供する。
交差・屈折・sensor投影・重心・RMS²は `SimulationRuntime` の共通C++核を使用する。
[幾何点像核](OPTICAL_SPOT.md)は任意の指定面列を扱い、このprofileだけが以下の形状に固定される。
Web入口は `tools/lens-spot-lab.html`。入力変更では実行せず、明示ボタンでオフライン参照を計算する。
ゲーム描画へのレンズ効果挿入は後続の受入である。

## 入力と測度

version1 / kind `synthetic-biconvex-geometric-spot`。R=+0.05m / −0.05m、頂点Z=0 / 0.005m、
発射面Z=−0.01mの合成両凸レンズ。開口半径は0.00001..0.015m、sensorZは0.00501..1m。
前後の同じ開口で面が交差しない条件 a² < R*t−t²/4 は最大開口でも成立する。
sensorは半径1mの物理的な円盤で、Canvasの表示窓とは独立している。
描画倍率・可視領域で統計対象を切り捨てない。欠落は指定面列上の幾何判定であり、未実装の筐体による吸収ではない。

平行光は有限位置を持たず、指定した生のdirectionを使う。有限物点はpositionから各節点への差を
C++のoutward区間減算で作り、通常double減算で消える下位項も囲む。巨大な有限距離で無限遠を偽装しない。

半径方向Nr=1..16、角方向Na=4..64の偶数。r_i=a*sqrt((i+1/2)/Nr)、
θ_j=2π(j+1/2)/Naで半周を生成し、残る点を正確な符号反転の対として配置する。
全節点の重みは1/(Nr*Na)。r²層が等幅なので一様な瞳面積の中点求積となる。
節点のsin/cos/sqrtは丸められたbinary64入力であり、連続瞳全体を包むものではない。
同じ節点と元重みをすべての波長で使う。有限点像の数値包含と、標本数を増やした積分収束を混同しない。

既定の合成CauchyはA=1.48、B=6.05e−15m²、C=0、有効帯400..700nm、点波長450/550/650nm。
Cauchy係数/有効帯/1..8点波長もprofileへ保存する。実在ガラスや実測値ではない。
各波長の全phase-index区間を核へ渡し、中央値で屈折しない。分散が非物理/未解決ならchannel resultは空とする。
profileは未知field、非有限数、範囲外を拒否する。保存/読込はsource・材質・波長・予算を保持し、GUIで変更しない値を既定値へ戻さない。

## 品質と結果

有限個のrayを指定した透過2面へ通す。routeのpower包絡は幾何重みに掛けない。
波長の点色は表示ラベルで、放射束やRGB輝度ではない。有限物点の距離/余弦や
平行光の入射面照度、偏光の多面輸送は将来の放射測定モデルで定義する。
同じOPLでも発射面の位相規約を定義せず波面・干渉を主張しない。

`settings`はmaximumParameterWidth、maxSqrtRefinements、maximumSampleEvaluations、
maximumTotalSqrtRefinements、maximumPhaseWidth。既定64点/λ、sample予算1024、報告sqrt総予算1000000。
1024点へ増やした同じprofileは総sqrt予算へ達し得る。その場合、未実行と未知を保持しstatsは空になる。
任意に予算を4000000へ増やすprofileも保存できる。黙って標本数を下げたり残った点を正規化しない。
処理時間は各操作の実測で、オフライン参照の時間を60fpsゲームの合格根拠にしない。

受入: 保存読込同一性、等面積の解析的r²平均a²/2、対称性、C++の独立重み付き重心/分散、
厚レンズ近軸極限、球面収差、波長差、有限物点、計算予算と復帰。有限標本の観測はreportsへ残す。
連続瞳の保証、放射画像、回折PSF、coating/散乱、全ghost探索と連続最適焦点は未完。
