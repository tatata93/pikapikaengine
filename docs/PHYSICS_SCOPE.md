# 追加要件: 空気・水の流体と構造損傷

2026-11-03のユーザー追加指示。最終製品の要求として保持し、単なる見た目の変形や汎用剛体を完成扱いにしない。通常の追加要望は適切な依存順で取り込み、明示的な即時・至急指示があれば順位を見直す。

## 要求される結果

- 空気・水などの流体を計算し、航空、車両、水上船、潜水艦等のシミュレーターを開発できる共通基盤。
- 衝突による薄板（例: ボンネット）の残留変形と、被弾による装甲の塑性変形・材料損失を物理モデルに基づいて再現すること。
- シーン原本、実行時形状、質量・慣性、衝突、流体との接触面、音響・描画の形状変更が整合すること。
- 力学的な計算、ゲーム用調整、描画の近似を明示し、誤差・負荷・適用範囲を検証すること。60fpsの共通目標は維持し、重い参照計算とは分離すること。
- 自動車・航空機・鉄道等の運動学と専門物理モデルを、共通の力・トルク・接触・拘束の計算へ接続すること。タイヤ、車輪とレール、地面、関節、多数物体、流体との接触を用途ごとに増やし、形状・材質・速度域の対応範囲を明示すること。

## 未完として残す項目

流体場、材料の弾塑性、破断・装甲の材料損失、専門車両/空力/鉄道モデルは未実装。静水圧の数値核と6自由度の球/平面接触の初段を実装し、実績は `FLUID_MODELS.md` / `DYNAMICS.md` と各試験を参照する。ボックス接触とブーストコントローラー、距離音響、頂点の手動編集を要求全体の代替とは扱わない。対象材料の弾性率、降伏応力、塑性硬化、破壊条件、板厚、ひずみ速度依存、接触と熱の扱いはモデル選択時に出典・単位・仮定・未対応範囲を記録する。

対象機材・通常負荷を定めて性能を測定する。負荷の大きい流体場や破壊の計算を単に省略したり、品質を黙って落として合格にしたりしない。局所計算、事前計算、適用範囲を限定した近似は、差と誤差を明示して比較する。

## 現行のW1衝撃とW2支持力照会の境界

[CONTINUOUS_WORLD.md](CONTINUOUS_WORLD.md)のW1は、球proxy/静的平面について保持force/torque下の
衝撃間を進め、誤差guard内で少し早く応答して残時間を再照会するtransactional tickである。
初期支持・持続接触・接線・未解決や予算不足を、そのまま成功の運動へ変換しない。

今回追加の[SUPPORT.md](SUPPORT.md)はW2の最初のnormal-only基盤で、現在姿勢に対するread-only照会である。
明示gap band全体に入る近似境界を使い、僅かな正gapも支持対象になり得ることを返す。
構造的な法線速度zeroだけをrest LCPへ入れ、確定した微小接近はimpact_required、
正の法線速度は離反lambda0とする。法線加速度には保持荷重と球対の中心距離の曲率 |u_t|²/d を含める。
球面の物質点の向心加速度を、平面支持からrω²として差し引くモデルではない。

反力候補を独自PGSで求め、表現済みlambdaを原入力の区間行列へ戻して負の加速度と相補性を監査する。
conditioning gateは通常doubleの検査で、全区間行列のSPD・力の一意性の証明とは分ける。
許容値は単位付きで公開し、nominal収束だけで成功にしない。21群にはmg、荷重stack、
非直交2面、片側の離脱、異質量球の曲率、悪条件・予算・失敗後再利用がある。
Worldの物理state・保持荷重・clockを変えず、共通ABIの3関数とJS querySupportでsnapshotを取得する。
[支持ラボ](../tools/support-lab.html)もこの瞬間照会を使い、成功反力と失敗候補を区別する。

この進捗は、W1とW2の統合、支持を保つ時間積分、摩擦支持、接触manifold、一般形状、
長時間のstack/転がり安定性、流体との接触連成、車両/航空/鉄道の専門モデルを完了したものではない。
後続は保持荷重・支持・衝撃の切替と残時間の整合、拘束残差/仕事・エネルギーと刻み幅収束を検証する。
CFD、弾塑性・材料除去、描画/質量/接触面の損傷更新の未完項目も維持する。
