# 次の光学受入: 静的複数面の最近傍

W2公開b0a7a6a後に採用した契約案。現在は[OPTICAL_SELECTION.md](OPTICAL_SELECTION.md)として実装・公開検証済み（コード9c3387e）。以下は設計時の根拠を残す。
ユーザーの「任意で厳密に光学計算」を、モデル・入力・誤差・未確定を追跡できる選択経路として進める。
最初は撮像や全ghost探索から独立したpureな一回の幾何照会とする。

## 入出力

入力は既存の全区間BoundedRayと、stable ID付きPlaneDisk/FullSphere/SphericalCapのspan。
出力はhit/miss/unresolved/invalid_input/budget_exceeded/numerical_failure、各面の診断と計数。
成功hitのときだけ、一意な同じ最近傍IDと元の全Hit包含を付ける。
要求した閉parameter区間に対して保証し、tMin以前の可視性は保証しない。
面数・照会数・平方根処理を制限し、未検査面を残して成功しない。
重複ID・不正な形状/設定は入力不正とし、面の入力順で物理的なtie-breakをしない。

## 証明する条件

既存primitiveのhitは、全ray族員が同じ順序の最初の有効根を持つ契約。
単に候補root区間があることとは違う。勝者Aはこのhitを持ち、他の全ての面Bについて
miss、またはA.t.upper < B.t.lowerを要求する。比較は同じrayのparameterで行う。
全部missだけが全体miss。残る曖昧さはunresolvedで成功Hitを返さない。
後方のunresolvedがあっても、閉prefix [tMin,A.upper] でBのmissを別に証明できれば排除可能。
これは拡張候補であり、初版の必須最適化にしない。prefixの接線等で証明できなければ未確定を保つ。

区間の非重なりは十分条件で、完全な最近傍判定ではない。
O=0、dZ∈[1,2]、A:z=2、B:z=3では必ずAが先でも、tA=[1,2]とtB=[1.5,3]は重なる。
相関を使わない初版がunresolvedを返すことは正しい。算術精度を増やしても本物の族幅は消えない。
逆に前方Bの開口を一部rayだけが通る場合、そのunresolvedを無視して後方Aを選べない。
接線、同時面、aperture/cap境界も不確定として扱う。根の配列順ではなく最初の有効根を使う。

## self-hitと媒質

t=0を隠さず、source IDの丸ごと除外や暗黙のepsilon offsetを入れない。
単位球の表面から内向きに進む根は0と2。source球を除くと正しい出口も失う。
epsilon cutoffはepsilon/2にある別面を失う。要求区間の変更としてのみ明示できる。
spawn_rayの独立boxは面上との相関を失うため、sourceタグだけでt=0根のみの除外を証明しない。
自動継続には、生成面上の関係と根の同一性を維持する別の表現/受入が必要。

最近傍の幾何核へ媒質選択を混ぜない。後続層でfront/back medium IDとcurrent IDを照合し、
不一致を理由に近い面を飛ばさない。屈折率区間が重なるだけでは同じ媒質にならない。
反射は媒質IDを維持し、透過は反対側へ更新する。開始媒質の空間的正しさや、disk群が
閉領域を構成することまで局所照合で保証しない。開口外を暗黙の筐体や遮光材にしない。

## 最小検証

- 確定した前後2面と全miss、面リストの並べ替えで同じ結果。
- 族の中で面順が変わる場合、相関により実順序は一定でも包絡が重なる場合。
- 前方開口のhit/miss混在、接線、同時面、後方だけの未確定。
- t=0、球の出口、明示cutoffより近い別面。
- capの前方根の棄却と後方有効根。
- 不正ID/形状/環境、予算失敗、同じ入力の正常再利用。
- 独立解析参照、Native/standalone実WASM、共通APIへの接続は順に検証する。

設計の根拠は現行のOPTICAL_BOUNDS.md、OPTICAL_ROUTE.mdと対応する原著C++契約。
新しい第三者コード・材質/処方データは導入しない。撮像・収差画像・全ghost列挙・
偏光/位相の継続・回折・フレアの描画接続と精度/性能比較は依然として後続である。
