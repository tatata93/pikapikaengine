# FK/IK・制御ブロック図の設計候補

2026-11-03。ユーザーは「ロボット運動学・逆運動学・Matlab/Simulink的な制御図もできる方がよいか」と相談した。推奨は関節/制御の共通API・データ・検証を先に作り、GUIをその上に載せる順。既存のFK/IK要求へ接続する候補であり、この文書だけで実装済みとしない。

- 関節木と安定ID、リンク長・局所軸・基準姿勢・角度/移動制限。FKは関節状態から姿勢、IKは目標姿勢から制限内の関節状態を計算する。到達不能・特異点・残差を返す。
- IK目標と、アクチュエーターが物理的に実現する運動を分ける。関節制御はトルク/力を出力し、質量・慣性・接触・摩擦・可動域・出力飽和をソルバーが評価する。運動学で姿勢を直接設定する表示モードも、力学制御とは区別する。
- センサー、目標値、PID、フィルター、遅延、加算・ゲイン、飽和、モーター等を信号線で結ぶデータ形式。型・単位・サンプル周期・遅延・実行順序と乱数種を保存する。固定周期・複数周期の受け渡しを定義し、未解決の代数ループを検出する。
- 歩行/飛行/着地/故障等のモード切替には状態遷移図を使う。信号のフィードバックと実行手順のフローチャートを混同しない。
- CLI/コードと将来のGUIが同じグラフ原本を扱い、信号を時間軸で記録する。再生・停止・コマ送り、入力リプレイ、ステップ応答・定常偏差・飽和・安定性の検証を用意する。

検証例は2リンク腕の既知FK/IK、関節制限と到達不能、接地中の脚、トルク制限付き追従、制御周期と描画周期を変えた再現性。全ロボット構造の無条件自動制御や、Matlab/Simulinkとのファイル・ソルバー完全互換は未定義である。

確認した公式資料: MathWorks R2026b [inverseKinematics](https://www.mathworks.com/help/robotics/ref/inversekinematics-system-object.html)（目標姿勢/関節制限/解の残差）、[What Is Sample Time?](https://www.mathworks.com/help/simulink/ug/what-is-sample-time.html)（ブロック実行周期、単一/複数レート）。本文を2026-11-03に確認。概念の比較に用い、コード・図・製品を取り込んでいない。
