# 学習教材の編集・検証

入口は[index.html](index.html)、必須の最初の実演は[flame.html](flame.html)。HTML・CSS・classic JavaScript・自作SVGのみ。外部依存を追加していません。

本文の編集元は各HTMLそのもの、図の原本は`diagrams/*.svg`。生成された別のHTMLはなく二重編集しません。図を変更したら`../legal/ASSETS.md`のハッシュを更新します。

## 実行

リポジトリのルートから次を実行します。

```powershell
node --test docs/learn/learn.test.mjs
npm start
```

配信先の`/docs/learn/`または`/docs/learn/flame.html`へアクセスします。教材に限ればHTMLを直接開く`file://`でも本文・SVG・検索・操作を利用できます。ゲーム本体の配信条件とは別です。

## 2026-11-03の確認

- Node.js v24.14.1。計算・UI状態・静的構造を自動検証。
- 正弦波の既知の1/4周期、位相、ノイズの決定性・種差・境界の連続性、全モードの入力範囲と変位上限。
- 30/60/120fpsの同一時刻での一致。再生時計は描画枚数でなくタイムスタンプに依存。
- 実際のUIスクリプトをCanvas/DOMのテストハーネスで実行し、初期停止・再生・停止・コマ送り・リセット・非表示時の停止を検証。
- HTMLの重複ID、画像のalt、ローカルリンクとリンク先のアンカーの存在を検証。

このハーネス試験は、実ブラウザの描画やレイアウトの目視検証を代替しません。実ブラウザ確認を行ったら、ブラウザ版・画面寸法・試験内容を節目のレポートへ追記してください。デモの描画頻度は実ディスプレイへの提示fpsの測定結果ではありません。

## ブラウザでの観察手順

1. 入口を広い画面と幅375px程度で表示し、図の欠落・横はみ出し・重なりを確認。
2. 検索で`audio`または`音`、分類で描画を選び、絞込みと目次からの復帰を確認。
3. 炎で再生→停止→コマ送り→リセット。停止時に時刻が変わらず、1コマが1/60秒であることを確認。
4. 各モードを選び、A=0、f=0、ノイズ=0、変化速度=0、シード変更を観察。
5. 30/60/120fps相当の間引きを比較。8Hz・合成波では速い成分の折返しを観察。
6. Tab・矢印・Enterで操作でき、初期停止と非表示タブから戻った停止が保たれることを確認。
7. JavaScriptを止めても本文と図が読み取れること、外部通信に依存しないことを確認。
