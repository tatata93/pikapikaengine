AUTHORING 01 / EDITABLE SOURCE GEOMETRY

頂点を動かす。
形を保存する。

箱の角をひとつ動かすと、つながる面も一緒に変わります。エンジンは編集しやすい原本と、画面へ描くためのデータを分けて管理します。

分類: モデリング / 入門 / 前提: 3D座標、三角形の描画 / 2026-11-03

頂点と、三角形の接続

頂点（Vertex、バーテックス）は立体の形を決める点です。座標は[x, y, z]の3つ、単位はm。メッシュ（Mesh）は頂点と、それらをつなぐ面を集めたものです。この版は面を三角形として保存します。

箱には8つの角があります。四角い面を2つの三角形へ分けると、6面×2で12三角形。各三角形は点の座標を複製せず、たとえば[4, 5, 6]のように頂点番号（Index、インデックス）を3つ持ちます。ひとつの頂点を動かすと、それを参照しているすべての三角形が変わります。点と面のつながり方をトポロジー（Topology）と呼びます。

ローカル座標は形そのものの座標、世界座標はシーンへ置いた後の座標です。頂点編集はローカルのmを変更します。機体や物体全体を移動するposition、全体の寸法倍率scale、Y軸の回転yawとは別です。scaleは単位なし、yawはradです。

同じ原本をCLIで作って編集する

リポジトリのルートで、次の順に実行します。Node.jsを使い、追加のnpmパッケージは不要です。出力先に既存ファイルがあると置き換えるため、例では別名へ保存します。

node tools/author.mjs mesh-box box.scene.json 2 2 2
node tools/author.mjs mesh-vertex box.scene.json mesh-1 6 1.5 1.6 1.4 edited.scene.json
node tools/author.mjs help

最初の命令は、一辺2mの箱を持つシーンを作ります。物体の安定IDはmesh-1。次の命令は、その物体の頂点6を[1.5, 1.6, 1.4]mへ動かします。物体のIDと、三角形が参照する頂点番号は保ちます。保存したedited.scene.jsonは、制作画面のシーン読込で開けます。

JavaScriptから同じ編集APIを使う

import {createBoxMesh, moveVertex, meshBounds} from './engine/mesh.mjs';
import {Scene, meshEntity} from './engine/scene.mjs';

const source = createBoxMesh([2, 2, 2]);
const edited = moveVertex(source, 6, [1.5, 1.6, 1.4]);
const scene = new Scene();
scene.add(meshEntity('mesh-1', edited));
console.log(meshBounds(edited).size); // [2.5, 2.6, 2.4] m
const saved = scene.save();
const reopened = Scene.load(saved);

これは実装済みAPIを利用するコードです。Node.jsのES module、またはHTTP配信したブラウザのmoduleで実行します。本ページの本文と図はfile://でも読めますが、このコードをページ内で自動実行はしません。

ひとつの原本から、描画と衝突を更新する

法線（Normal）は面に垂直な向きで、光の計算に使います。この版のcompileMeshは各三角形にひとつの法線を作り、位置3値＋法線3値のFloat32へ展開します。フラットシェーディングでは隣の面との境界がくっきり見えます。点を共有していることと、面の明るさをなめらかにつなぐことは別です。

AABB（Axis-aligned bounding box、軸に平行な境界箱）は、X/Y/Z各軸の最小値と最大値から作る箱です。形全体を囲むため、複雑な形の空洞も箱の一部として衝突します。これは正確な三角形単位の接触ではありません。回転・拡大・位置を含めた世界座標の境界を導き、原本を編集したときは作り直す必要があります。

法線は三角形の頂点の順番でも反転します。右手系でn=(b−a)×(c−a)を正規化した向きを使います。a/b/cは頂点位置[m]、×は外積、長さで割ったnの大きさは1、単位なしです。光と法線の図で明るさとの関係を確認できます。

この段階でできること・未対応のこと

今回の原本形式は{version:1, positions:[...], triangles:[...]}。これを含むシーンはversion 2です。旧version 1の箱シーンを維持し、メッシュ追加時に新しい版へ進めます。

  • 箱の原本作成、単一頂点の移動、検査、保存・再読込。物体IDと既存の面接続を維持。
  • 1メッシュは最大65,536頂点・131,072三角形。位置は有限の±1,000,000m以内。シーン全体には別の上限と読込サイズ上限があります。
  • 範囲外の番号、同じ頂点の重複、面積がほぼ0の面を拒否。外積の長さの2乗が10⁻²⁴m⁴以下、またはFloat32へ変換すると面が潰れる形は保存対象にしません。
  • 面の追加・削除、押出し、穴埋め、UV、なめらかな法線、外部形式の取込み、地形専用編集は未対応です。

頂点編集と物理的な損傷は別です。角を動かして凹ませても、材料・応力・塑性変形・破壊・エネルギー収支を計算したことにはなりません。ボンネットの凹み、装甲のえぐれ、流体による荷重や空気・水の専門シミュレーションへつなぐ基盤の初段です。厳密な損傷物理は未完成です。

形の作成と保存が動いても、作品全体の60fps維持を証明するものではありません。頂点・面数に加え、描画・衝突・音響・編集後の再構築時間を実機で測る必要があります。性能の測定と限界も確認してください。
