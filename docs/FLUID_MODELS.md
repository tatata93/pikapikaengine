# 静水圧・排水体積・浮力の最初の検証可能なモデル

更新・資料確認: 2026-11-03。

実装: [`engine/hydrostatics.mjs`](../engine/hydrostatics.mjs)。試験: [`tests/hydrostatics.test.mjs`](../tests/hydrostatics.test.mjs)。追加ライブラリなし。独自実装の三角形切断・面積分を、独立した箱・四面体の理論値と比較する。

これは密度一定の静止流体と水平な水面に対する力の計算核であり、CFDや潜水艦・航空機・車両・鉄道シミュレーターの完成ではない。現在のゲーム、C++、WASM、剛体積分器への接続は未実装。実機の性能は未計測。単体試験の成立を60fps達成と混同しない。

## 対象と入力の前提

- SI単位、右手系、+Yが鉛直上向き。重力の大きさgは正、作用方向は−Y。
- 流体は一定密度ρ、静止・非圧縮、一様な重力、水平な外部水面 `y = waterLevel`。水面自体は変形しない。
- 水面より上の気体は一様な基準圧力だけを持つとし、その密度・重量による浮力と圧力勾配は省略する。密度の異なる水と空気を同時に積分する二流体モデルではない。
- 流体が接する密閉形状を、番号付き頂点と三角形の外側表面として渡す。`mesh.mjs`の原本形式を再利用し、原本を書き換えない。
- 各辺は逆向きに使う2つの面を持ち、各連結shellの符号付き体積は正。開いた形、面の向きの不一致、非多様体の辺、全体や一部shellの裏返しを拒否する。
- 複数shellは互いに重ならない独立した密閉体を前提とする。自己交差、shell同士の重なり、入れ子の空洞を自動検出・Boolean統合する機能はない。辺と体積の検査だけで、任意の入力が物理的に有効な固体であると証明したとはしない。
- 正の非一様scale、position、yawまたは単位quaternionを適用した世界座標で積分する。鏡映する負のscaleは拒否。quaternionは `[x,y,z,w]`、長さ1からの許容差10⁻¹⁰。yawとquaternionの同時指定は拒否。
- 原本の制限に加え、変換後の位置と水面・重心は有限の±1,000,000m以内。これは対応精度を全域で実証した保証ではなく、入力を有限な範囲に制限する境界。大きな座標では浮動小数点の丸めに注意する。

## 静水圧と大気圧の扱い

深さdに対するゲージ圧力を、次で定義する。

```text
d = waterLevel - worldY [m]
p = ρ g max(0, d) [Pa = N/m²]
ρ: 密度 [kg/m³], g: 重力加速度の大きさ [m/s²]
```

`hydrostaticPressure(depth, {density, gravity})` は水面より上で0、下でこの式を返す。既定値はρ=1000kg/m³、g=9.80665m/s²。密度は温度・塩分から求めた値ではなく、呼出し側が指定する仮定値である。海水の密度・圧力依存を自動計算していない。

一様な大気圧p₀は密閉した外側表面全体に作用すると、合力と合トルクへの寄与が相殺するため、この浮力核では省略する。濡れた面だけへp₀を足す扱いはしない。船内圧・外圧差による船殻の応力、座屈、浸水、圧壊を計算するためには絶対圧や内部圧も必要であり、この省略された浮力だけから損傷を決めてはいけない。

## 三角形の切断と解析積分

世界へ変換した三角形を `y <= waterLevel` の半空間で切断する。交点は辺の線形補間で求め、交点のYは水面に一致させる。できた多角形を同じ向きの三角形へ分割する。人工的な水面の蓋は、ゲージ圧力が0なので力へ寄与しない。

切断後の三角形に対し、Aを面積[m²]、nを外向きの単位法線、pᵢを3頂点の圧力[Pa]、rᵢを指定重心から頂点までの世界ベクトル[m]とする。

```text
P = p₁ + p₂ + p₃                    （3頂点のゲージ圧力の和）
F_triangle = -n A P / 3              [N]
M_pressure = A/12 Σᵢ rᵢ (P + pᵢ)    [N m]
torque_triangle = -M_pressure × n    [N m]
```

三角形の面内ではpとrが線形なので、r×圧力によるモーメントは2次の式になる。重心一点に平均圧力を掛けるだけでは、このモーメントは一般に正しくならない。実装は線形・2次の三角形積分を解析的に評価する。ここで「解析的」は数式の次数に対する厳密性であり、浮動小数点の丸めがない意味ではない。

合力・トルク・面積などの和には補償加算を使う。符号付き体積は各shell内の基準点から測り、平行移動による桁落ちを減らす。数値範囲を超えた出力は、成功扱いのNaNではなくエラーにする。

## 排水体積と浮心

合力の鉛直成分から `V = F_y / (ρg)` [m³]を求める。正しい密閉形状と静水圧の条件では、水平合力は0、浮力はρgVとなる。実際の返り値には丸めによる小さな水平残差も残し、無条件に0へ書き換えない。

浮心（center of buoyancy）は、水面下にある排水体積の重心である。水面を基準とした `h = y - waterLevel` と、平行移動したX/Z座標を使い、発散定理から別途体積の一次モーメントを求める。人工的な蓋ではh=0であり、次の表面積分の寄与も0になる。

```text
V      = ∫wet h n_y dA
∫V x dV = ∫wet x h n_y dA
∫V z dV = ∫wet z h n_y dA
∫V h dV = ∫wet (h²/2) n_y dA
```

三角形上の線形関数a、bについて、使う積の積分は以下。

```text
∫triangle a b dA = A/12 { (Σᵢ aᵢ)(Σᵢ bᵢ) + Σᵢ aᵢbᵢ }
```

体積の一次モーメントをVで割り、世界座標へ戻して浮心を得る。排水体積が0なら浮心は `null`。トルクは圧力面積分から直接計算し、浮心に浮力を置いて作った値だけで正しさを主張しない。試験では両者の関係に加え、既知の偏心トルクも検証する。

`wetArea` は水面以下の実表面積[m²]。人工的な蓋の面積は含めない。水面と一致する面は圧力0だが、その接触面積は含み得る。

## APIの例

```js
import {createBoxMesh} from './engine/mesh.mjs';
import {hydrostaticForces, quadraticDrag} from './engine/hydrostatics.mjs';

const result = hydrostaticForces(createBoxMesh([2, 2, 2]), {
  density: 1000, gravity: 10, waterLevel: 0,
  position: [0, 0, 0], scale: [1, 1, 1], yaw: 0,
  centerOfMass: [1, 2, 3], // 世界座標。省略時はposition。
});
// force ≈ [0, 40000, 0] N
// torque ≈ [120000, 0, -40000] N m
// submergedVolume = 4 m³, centerOfBuoyancy = [0, -0.5, 0] m
// totalVolume = 8 m³, wetArea = 12 m²

const drag = quadraticDrag({
  velocity: [3, 4, 0], current: [0, 0, 0],
  density: 1000, dragCoefficient: 0.8, area: 2,
});
// force = [-12000, -16000, 0] N
// relativePower = -100000 W
```

返り値は `force`, `torque`, `wetArea`, `submergedVolume`, `centerOfBuoyancy`, `totalVolume`, `shells`。`force` は流体からの合力だけで、自重−mg、推進力、剛体接触、操縦力を含まない。外側の積分器がそれらを合成する。

## 一様流中の係数抗力は別の近似

静水圧にcurrentを混ぜない。`quadraticDrag` だけが一様な流速current[m/s]と物体速度velocity[m/s]を扱う。

```text
v_rel = velocity - current [m/s]
F_drag = -1/2 ρ Cd A |v_rel| v_rel [N]
P_rel = F_drag・v_rel <= 0 [W]
```

Cdは単位なし、AはCdと対応した基準面積[m²]で、両者を明示指定する。形から勝手にCdを決めない。抗力係数は一般に形状・姿勢・Reynolds数・Mach数などの条件に依存する。この関数は与えられた係数に対する計算だけで、粘性、剥離、後流、造波、翼の揚力、圧縮性を解かない。

相対速度に対する仕事率は非正だが、流れている流体が世界座標で物体を加速することはある。物体の世界速度との内積まで必ず非正だとは扱わない。流体側の反作用やエネルギー更新は未実装。回転する物体の各点の相対流速や、抗力の作用点・トルクもこの単一係数関数の対象外。

## 実際に行った検証

`node --test tests/hydrostatics.test.mjs`。Node.js v24.14.1、14試験成功。

| 試験 | 独立した基準・条件 |
|---|---|
| 深さと圧力 | ρ=1000、g=10、深さ2.5mで25,000Pa。水面以上は0 |
| 一辺2mの箱 | 乾燥V=0、半没V=4m³/F=40,000N/浮心y=−0.5m、全没V=8m³/F=80,000N |
| 水面を連続的に変更 | 箱の面積4m²×水面下高さ。水面が頂点を通る条件も含む |
| 平行移動・深さ | 水面と物体の同時移動で合力・トルク不変。全没後は深さだけ増やしても浮力不変 |
| 非一様拡大・yaw | 2×4×6mの箱の半没V=24m³、浮心y=−1m |
| 90度roll・任意の傾き | 長方体の既知の軸交換、中心対称の傾いた箱の半分の体積 |
| 偏心トルク | 浮心(0,−0.5,0)、CoM(1,2,3)に対して(120000,0,−40000)N m |
| 面の再分割 | 変形した箱を2回細分割しても、力・トルク・面積・体積・浮心が一致 |
| 斜面を持つ四面体 | 全体から乾いた小四面体を引く独立導出。V=7/6m³、浮心(15/28,11/28,15/28)m |
| 密度・重力 | 浮力とトルクは比例し、排水幾何は不変 |
| 入力の失敗 | 開いた面、裏返り、方向不一致、非多様体、体積0、負scale、非単位回転、NaN/桁あふれ等を拒否 |
| 抗力 | 既知の3-4-5速度、流体と物体の同速度、相対流速不変性、非正の相対仕事率 |

比較許容差は通常10⁻⁸の絶対値。ここで試したm/N/N mの範囲の単体試験値であり、すべての幾何・座標範囲・動的場面の誤差上限ではない。CFDとの比較、実測水槽、実機の船体応答、長時間安定性、CPU予算の検証は未実施。

## 一次資料と確認範囲

すべて2026-11-03に本文を確認。図・コード・文献本文の転載なし。式からの三角形積分の組立て、コード、試験データは本プロジェクトで作成。

- [OpenStax University Physics 1, §14.1 Fluids, Density, and Pressure](https://openstax.org/books/university-physics-volume-1/pages/14-1-fluids-density-and-pressure): 密度一定の場合の深さに対する圧力と、圧力が面の法線方向に働く条件を確認。密度変化のある大気まで同じ定数密度モデルで解けるとはしない。
- [OpenStax University Physics 1, §14.4 Archimedes' Principle and Buoyancy](https://openstax.org/books/university-physics-volume-1/pages/14-4-archimedes-principle-and-buoyancy): 浮力と排水した流体の重量の関係を確認。部分・完全な浸水に対する検証の基準。
- [UCLA David Bauer, Physics 5B: Buoyancy](https://dbauer.physics.ucla.edu/5b/10-buoyancy/): 全没物体で一定の表面圧と深さの項が相殺する導出を確認。船殻の構造圧力計算を省略してよい根拠にはしない。
- [Purdue MA261, §17.8 The Divergence Theorem](https://www.math.purdue.edu/~chenjk/MA26100S23/Lesson%2036%20(17.8-1)-acc.html): 閉じた表面の外向きフラックスと体積積分の関係を確認。浮心のh、xh、zh、h²/2という具体的な場の選択は、本モデルでこの定理から導出したもの。
- [NASA Glenn, Drag Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/): Cd、密度、基準面積、速度の2乗の係数抗力と、係数・面積の対応が必要なことを確認。NASAの係数データを採用したものではない。
